# USER TEST

**Owner:** Story lead (runs it). The Methods lead observes for statistical misreadings. **When:** H12–H14, with 2–3 people outside the team (students if possible).

## Script (about 7 minutes per person)
1. "Thanks! We're testing the app, not you. Please think out loud."
2. **Task A:** "Find out whether summers in Wisconsin are getting hazier from smoke."
3. **Task B:** "Is that a real trend? How sure are we?"
4. **Task C:** "What does 'Not proven yet' mean to you?"
5. **Optional Task D:** "Ask the partner something you're curious about."
6. "What was confusing? What would you tell a friend this app does?"

Don't help unless they are stuck for more than 60 s, and note when you do.
