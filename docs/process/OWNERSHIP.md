# OWNERSHIP: who may edit what

**Rule zero:** every file has exactly one owner, and only the owner edits it. To change someone else's file, ask the owner, who makes the change (usually within minutes). AI agents (Claude Code, Codex) follow this map too: an agent working for Oier must not edit Eleder's files, even to "fix" something.

|---|---|---|---|
| Eleder | Lead / integrator | Claude Code | `eleder/` |
| Oier | Coder B: data & stats | Codex | `oier/` |
| Ekaitz | Coder C: panel, charts & partner | Codex | `ekaitz/` |

## Shared files that are expensive to conflict on

- **`package.json` / `package-lock.json`:** Eleder installs every known dependency in the scaffold (the list is in his plan). Need another one? Open a **deps-only PR** (`<you>/deps-<name>`) touching only those two files and merge it right away; everyone else rebases. Never mix a dependency change into a feature PR.
- **`requirements.txt`:** Oier only.
- **`components/ui/` (shadcn):** Eleder pre-installs the primitives listed in his plan. Need another? Ask Eleder; it's a 2-minute PR.
- **Generated files** (`lib/api-types.ts`, `api/openapi.json`): never hand-edit and never hand-merge. On a conflict, take either side and run `npm run gen:types`.
