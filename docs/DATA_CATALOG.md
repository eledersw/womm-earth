Approval applies to the definitions and stated uses below, not every variable exposed by the dynamic POWER catalog or every region/period.

**Status values:** `candidate` (not yet verified for this app) → `in store` (provider/data availability confirmed) → `signed off` (Methods scientific review complete). Following the live-POWER decision, `in store` is a legacy status name: it does not imply a local series file. Successful checks here independently establish provider availability for these 16 rows; they do not claim an Oier review occurred. API integration and Edur's tone review are recorded separately in `docs/science/catalog/README.md`.

**Integration:** the production path discovers Manager metadata dynamically; it does not currently load these approved descriptions. The existing `scripts/catalog_to_json.py` targets local `.npz`/hero files and cannot export this live-only subset without those files. Oier owns the metadata overlay/export work. Keep the 13 table columns and status strings unchanged for compatibility; this documentation does not change the API contract.

**Units and periods:** use the AG community, matching the app's requests. Celsius is written °C here (provider code `C`); soil wetness uses dimensionless `1` with a 0–1 range. Energy uses `MJ/m^2/day`, not the RE community's kWh units. Periods below are verified finite coverage in the test rectangle through the completed year 2025, not a global availability guarantee. Grid sizes are latitude × longitude. The DOI column gives a source-method paper for processed POWER variables, not a fabricated POWER-release DOI; product DOIs are distinguished in the attribution list.

## Interpretation and provenance rules

- Trend statements above describe possibilities, not physical attribution. Explanations require cited process cards; a trend alone does not establish a cause.
- The live app averages cells returned for a region's **bounding rectangle**, weighted by cos(latitude). It currently does not apply the exact administrative polygon. Do not label a bounding-box result an exact state/country mean. Native grid resolution is not local measurement accuracy.
- Monthly mean daily precipitation/energy rates remain rates when averaged into a seasonal/yearly series. Do not call them annual totals. For extrema, averaging monthly maxima/minima is a different statistic from taking an annual maximum/minimum.
- Use °C/decade for temperature and the stated unit/decade elsewhere. For % variables, absolute slopes are percentage points per decade. Relative percent change is a separate calculation. Apply the ratio-scale/near-zero rules in METHODS; retain absolute pressure units.
- POWER Manager supplied no per-variable start/end dates in this check. The verifier inspects finite YYYYMM values, masks the response fill value and excludes YYYY13 annual summary keys. The request header's start date is not proof of data availability: AOD requested from 1984 contains finite values only from 2001. These checks cover one 2°×2° land rectangle, not all Earth regions or the deployed engine.
- Solar/cloud responses identify SRB and SYN1DEG; modern cloud/aerosol documentation describes SYN1deg Ed4.2, but the API header does not pin an edition. Record the actual provider version/source header with each case; do not label the entire 1984 record as a single CERES edition. Use 2001 onward for a simpler modern-source demo, with appropriate caveats.
